# CSS497-zarateod

My capstone project for the University of Washington CSSE degree Winter 2023

This project is an webapp which is focused on work of the property managers.
The application adds new residents to unoccupied properies, removes properties,create incidents, add maintenance to this incidents and track the records of incidents and maintenance for the particular property.

Backend is Mysql database , Node js
Front end React, Node js, Express.js



Tools: 
React,Express.js,Material UI, Mysql , VS code and Mysql workbench
